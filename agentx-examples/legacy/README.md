# Legacy examples (not maintained)

These four examples predate `agentx-py` 0.4. They use the old `agentx_sdk`
import with placeholder API keys and event types the platform no longer sends,
and `multi-agent-demo/` hard-codes a local checkout path (`~/agentx/sdk`) and a
`dev-token`. They do not run against today's API as written.

They are kept for reference only. Start from the sample agents one folder up
instead; each of those is tested against the platform on every change.
