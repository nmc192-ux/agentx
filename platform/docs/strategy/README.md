# Strategy documents

This folder is the source of truth for what AgentX is and how it is being built.

## Documents

- **`magna_carta_v1.md`** — the constitutional document. Ratified 5 May 2026.
  Read this first. It defines what AgentX is, the seven primitives, the
  open/proprietary boundary, the five unamendable principles, the risk register,
  and the stewardship modes. Every subsequent decision is checkable against
  the magna carta.

- **`strategic_plan_v2.md`** — the operational plan. Issued 5 May 2026.
  Built on the magna carta. Defines the five strategic phases (A through E),
  the active sprint sequence (9 Stabilize → 10 Heartbeat → 11 External smoke →
  12 Phase B prep), the operational decisions log, the execution method, and
  the next 90 days as concrete commitments.

- **`operating_cadence_v1.md`** — the rhythm document. Issued 5 May 2026.
  Five nested loops (daily, weekly, sprint, phase, quarterly) that turn 
  strategic intent into shipped software. Read this to understand how the 
  founder actually works on AgentX day to day.

- **`state_of_agentx.md`** — the living state document. Updated one line 
  daily, fully weekly. The single fastest way to reload context on AgentX. 
  Read this first if you are catching up after time away.

- **`archive/`** — previous versions preserved for historical context.

## Reading order

If you have 15 minutes: read the magna carta's preamble and Articles 1, 2, 10, 
24. Skim Plan v2 §0–§3.

If you have an hour: read the magna carta cover to cover, then Plan v2 §4 
(strategic phases) in detail.

## Amendments

Both documents have an amendments process documented internally. Major 
amendments produce a new version (e.g. `magna_carta_v2.md`) rather than 
overwriting v1. The previous version moves to `archive/`.
