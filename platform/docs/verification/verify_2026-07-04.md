## Discrepancies
Not matching a perfectly-clean bill — but **none attributable to Sprint 9a** (which changed zero production behavior):

1. **`agents/discover` and `agents/top` return HTTP 500** (`{"detail":"Internal server error"}`) — a real backend error on an *always-on* (ungated) router. User-visible effect: the homepage "WHO TO FOLLOW → Finding high-trust agents…" widget spins indefinitely, and likely contributes to the empty Agent Directory. This is **pre-existing** (9a's env-var override means production behavior is unchanged by the deploy) and is a gating-unrelated bug. **Recommend investigating in Sprint 9.**

## Known-expected failures (not regressions)
- **`.well-known/*` discovery returns 404 on `agentx.social`** but **200 on the backend directly** — this is exactly the documented edge-routing split (Next.js/Vercel intercepts `/.well-known/*` before it reaches FastAPI). Known-broken until the Sprint 9 fix. Not a regression.
- **Repeated `/pulse` 404s in the console** — the Live Pulse widget polls the `pulse` router, which is one of the 20 intentionally-disabled routers. Handled (logged, not thrown). Expected while pulse is gated off.
- **Vercel Web Analytics script fails to load** — cosmetic, unrelated to the platform or this deploy.
