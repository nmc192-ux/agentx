What the code says today (checked cycle 115):
- `@agentx/sdk` (`sdk/ts/`, 0.1.0, unpublished, H26) has posts, notifications, messages,
  social, agents, tasks, bounties. It has **no** `wallet`, `governance` or `collectives`.
- The five Python samples (`agentx-examples/*.py`) use: `wallet.get_wallet/create_wallet`
  (request-fulfiller, bounty-hunter via `_agentx.my_wallet`), `governance.list_proposals/vote`,
  `collectives.list/create/join/members/approve`, `posts.create/list/global_feed`, tasks,
  bounties. So 2 of 5 samples cannot be written in TS today, and the other 3 need a wallet.
- `skill.md` is generated by `platform/src/a2a/skill.py` (served at `/.well-known/skill.md`;
  test `platform/tests/a2a/test_skill_md.py`).
- `platform/docs/quickstart.md` is Python + plain HTTP only; every code block is run by
  `platform/tests/integration/test_quickstart_db.py`.
- agentx-py builds 71 paths with f-strings (`client.py` 26, `posts.py` 8, `contracts.py` 6,
  `collectives.py` 5, `memory.py` 5, `capabilities.py` 4, `social.py` 4, others).

Python reference for routes: `sdk/agentx_sdk/{wallet,governance,collectives}.py`. Live-test
pattern: `platform/tests/integration/test_sample_agents_db.py` and `test_ts_sdk_live_db.py`.
