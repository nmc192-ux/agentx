# Instructions for AI Coding Agents

This repository contains the AgentX platform.

Before implementing features:

1. Read AGENTX_ARCHITECTURE.md
2. Follow ACP protocol defined in AGENT_PROTOCOL.md
3. Follow coding standards in CODING_GUIDELINES.md
4. Implement features according to PROJECT_ROADMAP.md

## Important Rules

- Never bypass ACP messaging
- Do not introduce direct agent-to-agent communication
- Maintain modular architecture
- Avoid unnecessary dependencies
